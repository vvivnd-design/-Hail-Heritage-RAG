# Project Description

## Hail Heritage RAG | راوي حائل الذكي

**Course:** Modern Data Engineering for Advanced AI Systems  
**Academy:** SDAIA Academy

Hail Heritage RAG is an Arabic-first, governed Retrieval-Augmented Generation application designed as a capstone proof of concept for authorized museum and visitor-center knowledge in the Hail Region.

The application implements a complete document-to-answer RAG flow: document ingestion, data-quality validation, privacy-aware redaction, recursive chunking, multilingual embeddings, persistent vector storage in ChromaDB, top-k semantic retrieval, confidence thresholding, optional grounded LLM generation, source traceability, audit logging, and a retrieval-evaluation harness.

The repository intentionally distinguishes implemented local components from production extensions. Kafka, Lakehouse technologies, Kubernetes, and enterprise governance platforms are architectural roadmap options and are not presented as deployed components.
